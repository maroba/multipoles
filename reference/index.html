API Reference

multipoles.MultipoleExpansion

Perform a multipole expansion for a given charge or mass distribution.

Determines the spherical multipole moments of the given distribution and can calculate the solution of the electrostatic or gravitational potential based on the multipole expansion.

Create it from point charges with MultipoleExpansion.from_charges, from a charge density on a grid with MultipoleExpansion.from_density, from known moments with MultipoleExpansion.from_moments, or with a dict describing the distribution.

Attributes:

Name Type Description
l_max int

The maximum multipole moment of the expansion.
exterior bool

Whether this is an exterior expansion.
interior bool

Whether this is an interior expansion.
center ndarray

The expansion center.
center_of_charge ndarray | None

The center of charge, weighted by the absolute values of the charges. None for expansions created from moments.
total_charge float | None

The total charge. None for interior expansions created from moments.
prefactor float

The constant the potential and its derivatives are multiplied with.
validity_radius float

The exterior expansion converges outside, the interior expansion inside the sphere of this radius about the expansion center.
multipole_moments dict

The multipole moments q_lm (exterior) or I_lm (interior), with keys (l, m), in Racah normalization (see the theory section of the documentation).

dipole_moment property

The dipole moment vector p = Σ q (r - center), about the expansion center.

quadrupole_moment property

The traceless quadrupole moment tensor, about the expansion center.

Q_ij = Σ q (3 x_i x_j - r^2 δ_ij), with x = r - center, so that the potential is Φ = q / r + p·x / r^3 + Σ_ij Q_ij x_i x_j / (2 r^5) + ...

multipole_moments_array property

The multipole moments q_lm as array of shape (l_max + 1, 2 l_max + 1).

Index it as [l, m], with negative m wrapping around as usual in Python. Entries with |m| > l are zero.

grid_axes property

The 1D axes (x, y, z) of the grid, for expansions created from a density.

external_coords property

The 3D coordinate arrays (X, Y, Z) of the grid, for expansions created from a density.

rho property

The charge density, for expansions created from a density.

__init__(charge_dist, l_max, exterior=None, interior=None, center=None, charge_tol=1e-06, *, prefactor=1.0, tol=None, radius=None)

Create a MultipoleExpansion object for a given charge or mass distribution.

Parameters:

Name Type Description Default
charge_dist dict

Description of the charge distribution.

For discrete charge distributions (point charges) the dict must contain exactly the following items:

  • 'discrete': True
  • 'charges': a list of dicts, one for each point charge, with the items
    • 'q': the charge (positive or negative number)
    • 'xyz': the location of the charge in cartesian coordinates (tuple, list or array of length 3)

For continuous charge distributions (charge density) the dict must contain exactly the following items:

  • 'discrete': False
  • 'rho': the charge density on a grid (3D numpy array)
  • 'xyz': the grid, either the three 1D axes (x, y, z), or a 3-tuple of 3D coordinate arrays as returned by np.meshgrid(x, y, z, indexing='ij'). The axes may be unevenly spaced.

MultipoleExpansion.from_charges and MultipoleExpansion.from_density do the same without the dict.

 required
l_max int | str

The maximum multipole moment to consider (0 = monopole, 1 = dipole, etc.), or 'auto' to choose the smallest l_max for which the error bound (see error_bound) at distance radius from the center is below tol.

 required
exterior bool

Whether to perform an exterior expansion (default). If False, the interior expansion is used.

 None
interior bool

Whether to perform an interior expansion. Alternative to exterior; only one of both needs to be given.

 None
center array_like

The point (x, y, z) about which to expand. Defaults to the center of charge, weighted by the absolute values of the charges.

 None
charge_tol float

Fraction of the total absolute charge of a continuous distribution that may be ignored when determining the region where the expansion is valid (see validity_radius). Smooth densities like gaussians never vanish exactly, so without such a tolerance no point of the grid would count as outside the distribution.

 1e-06
prefactor float | str

The constant the potential, field and Hessian are multiplied with. 'gaussian' (default) is 1, 'SI' is 1 / (4π ε₀) for the electrostatic potential in SI units, and 'gravity' is -G for the gravitational potential of masses in SI units. Any number is fine, too.

 1.0
tol float

Only for l_max='auto': the error bound of the potential at distance radius, relative to Σ|q| / r, the potential the absolute charge would have there. Defaults to 1e-6.

 None
radius float

Only for l_max='auto': the smallest (exterior) or largest (interior) distance from the center where you will evaluate the expansion. For exterior expansions of charge densities it defaults to the distance from the center to the boundary of the grid.

 None

The exterior expansion converges only outside the smallest sphere about the center that contains all charge, the interior expansion only inside the largest sphere about the center that contains no charge. The radius of this sphere is stored in validity_radius. Evaluating the expansion at points where it does not converge emits an ExpansionValidityWarning. To turn these warnings into errors, use warnings.simplefilter("error", ExpansionValidityWarning).

Raises:

Type Description
InvalidChargeDistributionException

If charge_dist is malformed, the total absolute charge is zero, or the grid is invalid.
InvalidExpansionException

If interior and exterior contradict each other, or an interior expansion is requested with charge at the expansion center.
ValueError

If center is not a finite point in 3D, or l_max is not a non-negative integer or 'auto'.

Examples:

A discrete charge distribution: two point charges with positive and negative unit charge located on the z-axis:

>>> from multipoles import MultipoleExpansion
>>> charge_dist = {
...     'discrete': True,
...     'charges': [
...         {'q': 1, 'xyz': (0, 0, 1)},
...         {'q': -1, 'xyz': (0, 0, -1)},
...     ],
... }
>>> Phi = MultipoleExpansion(charge_dist, l_max=2)

A continuous charge distribution: the same charges, smeared out as gaussians on a cubic grid of edge length 16 centered at the origin:

>>> import numpy as np
>>> x, y, z = [np.linspace(-8, 8, 81)] * 3
>>> XYZ = np.meshgrid(x, y, z, indexing='ij')
>>> def gaussian(XYZ, xyz0, sigma):
...     g = np.ones_like(XYZ[0])
...     for k in range(3):
...         g *= np.exp(-(XYZ[k] - xyz0[k])**2 / sigma**2)
...     return g * (sigma**2 * np.pi)**-1.5
>>> rho = gaussian(XYZ, (0, 0, 1), 1.5) - gaussian(XYZ, (0, 0, -1), 1.5)
>>> Phi = MultipoleExpansion({'discrete': False, 'rho': rho, 'xyz': XYZ}, l_max=2)

Evaluate the potential at arbitrary points with Phi(x, y, z) or on the grid points of a continuous distribution with Phi[...], and the field with Phi.field(x, y, z). The examples of these methods use Phi and gaussian from here.

Evaluate the multipole expansion at points with given coordinates.

Parameters:

Name Type Description Default
*xyz float | array_like

The points where to evaluate the expansion: either their coordinates x, y, z as three numbers or arrays, or one array of shape (..., 3) of points. If three numbers are given, the expansion is evaluated at the single point (x, y, z). If arrays are given, it is evaluated at each point (x[i], y[i], z[i]). Arrays may have any shape; numbers and arrays are broadcast against each other.

 None

The value of the potential: a float for a single point, otherwise an array of the broadcast shape of the coordinates (or the shape of the array of points without its last axis).

error_bound(*xyz, l_max=None)

An upper bound of the truncation error of the potential.

For each charge q at distance s from the center, the error of the exterior expansion at distance r from the center is at most |q| (s/r)^(l_max+1) / (r - s); for the interior expansion, swap r and s. The bound is the sum over all charges, which are binned radially for speed. For continuous distributions, it ignores the fraction charge_tol of the charge that lies beyond validity_radius, as well as the integration error.

Parameters:

Name Type Description Default
*xyz float | array_like

The points, as for __call__.

 ()
l_max int

The order of the truncated expansion. Defaults to l_max.

 None

Returns:

Type Description
float | ndarray

The bound at each point, infinite where the expansion does not converge.

Raises:

Type Description
ValueError

If the expansion was created from moments without abs_charge.

Examples:

>>> bound = Phi.error_bound(30, 0, 0)

cartesian_moment(l)

The cartesian multipole moment of order l, a symmetric traceless tensor of rank l.

For the exterior expansion, it is the tensor M with Φ_l = M_{i1...il} x_i1 ... x_il / (l! r^(2l+1)), i.e. M = (2l-1)!! Σ q (x^l with traces removed): the total charge for l=0, the dipole moment for l=1, the quadrupole moment for l=2, the octupole moment for l=3 etc., all about the expansion center. For the interior expansion, it is the tensor of the l-th derivatives of the potential at the center.

Parameters:

Name Type Description Default
l int

The order, at most l_max.

 required

Returns:

Type Description
ndarray

The tensor, of shape (3,) * l.

Examples:

>>> quadrupole = Phi.cartesian_moment(2)  # shape (3, 3), same as Phi.quadrupole_moment

moments(normalization='racah', real=False)

The multipole moments in other conventions, as array indexed by [l, m].

Parameters:

Name Type Description Default
normalization str

'racah' (default) for the moments q_lm of this package, with the spherical harmonics C_lm = sqrt(4π / (2l+1)) Y_lm, or 'orthonormal' for the moments with the orthonormal Y_lm, e.g. as in Jackson's Classical Electrodynamics: sqrt((2l+1) / 4π) q_lm.

 'racah'
real bool

Return the real moments for the real spherical harmonics instead: [l, 0] is q_l0, [l, m] with m > 0 is √2 (-1)^m Re q_lm (the cosine part), and [l, -m] is √2 (-1)^(m+1) Im q_lm (the sine part). With Racah normalization, [1, 1], [1, -1] and [1, 0] are the dipole components p_x, p_y and p_z.

 False

Returns:

Type Description
ndarray

The moments, of shape (l_max + 1, 2 l_max + 1), complex unless real. Negative m wrap around; entries with |m| > l are zero.

power_spectrum()

The strength of each order l, sqrt(Σ_m |q_lm|²), for l = 0, ..., l_max.

Unlike the moments themselves, it does not change when the distribution is rotated about the expansion center.

Returns:

Type Description
ndarray

Array of shape (l_max + 1,).

shifted(center)

The same expansion about another center.

If the expansion knows its charges, the moments are recomputed about the new center. Otherwise, they are translated with the addition theorem of the solid harmonics: for exterior expansions, this gives the exact moments up to l_max about the new center, and the validity radius grows by the distance between the centers. For interior expansions, the result is the same truncated polynomial, so it has the same truncation error, and the validity radius shrinks by the distance.

Parameters:

Name Type Description Default
center array_like

The new expansion center.

 required

Returns:

Type Description
MultipoleExpansion

The new expansion.

Examples:

>>> shifted = Phi.shifted((0, 0, 1))

__add__(other)

The expansion of the combined charge distribution of two expansions.

Both must be of the same kind (exterior or interior) and have the same prefactor. The result has the smaller of both l_max. If both know their charges, it is computed from all charges, about the center of charge of both, unless an expansion center was given explicitly for the left operand. Otherwise, the moments of the right operand are translated to the center of the left one and added.
