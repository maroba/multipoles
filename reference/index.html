API Reference

multipoles.MultipoleExpansion

Bases: object

Perform a multipole expansion for a given charge or mass distribution.

Determines the spherical multipole moments of the given distribution and can calculate the solution of the electrostatic or gravitational potential based on the multipole expansion.

__init__(charge_dist, l_max, exterior=None, interior=None)

Create a MultipoleExpansion object for a given charge or mass distribution.

Parameters:
  • charge_dist (dict) –

    Description of the charge distribution.

    For discrete charge distributions (point charges) the dict must contain exactly the following items:

    • 'discrete': True
    • 'charges': a list of dicts, one for each point charge, with the items
      • 'q': the charge (positive or negative number)
      • 'xyz': the location of the charge in cartesian coordinates (tuple, list or array of length 3)

    For continuous charge distributions (charge density) the dict must contain exactly the following items:

    • 'discrete': False
    • 'rho': the charge density on a grid (3D numpy array)
    • 'xyz': the grid, a 3-tuple of 3D coordinate arrays as returned by np.meshgrid(x, y, z, indexing='ij')
  • l_max (int) –

    The maximum multipole moment to consider (0 = monopole, 1 = dipole, etc.).

  • exterior (bool, default: None ) –

    Whether to perform an exterior expansion (default). If False, the interior expansion is used.

  • interior (bool, default: None ) –

    Whether to perform an interior expansion. Alternative to exterior; only one of both needs to be given.

The expansion is done about the center of charge, which is weighted by the absolute value of the charges.

Raises:
  • InvalidChargeDistributionException –

    If charge_dist is malformed, the total absolute charge is zero, or the grid is invalid.

  • InvalidExpansionException –

    If interior and exterior contradict each other, or an interior expansion is requested with charge at the expansion center.

Examples:

A discrete charge distribution: two point charges with positive and negative unit charge located on the z-axis:

>>> from multipoles import MultipoleExpansion
>>> charge_dist = {
...     'discrete': True,
...     'charges': [
...         {'q': 1, 'xyz': (0, 0, 1)},
...         {'q': -1, 'xyz': (0, 0, -1)},
...     ],
... }
>>> Phi = MultipoleExpansion(charge_dist, l_max=2)

A continuous charge distribution: the same charges, smeared out as gaussians on a cubic grid of edge length 10 centered at the origin:

>>> import numpy as np
>>> x, y, z = [np.linspace(-5, 5, 101)] * 3
>>> XYZ = np.meshgrid(x, y, z, indexing='ij')
>>> def gaussian(XYZ, xyz0, sigma):
...     g = np.ones_like(XYZ[0])
...     for k in range(3):
...         g *= np.exp(-(XYZ[k] - xyz0[k])**2 / sigma**2)
...     return g * (sigma**2 * np.pi)**-1.5
>>> rho = gaussian(XYZ, (0, 0, 1), 1.5) - gaussian(XYZ, (0, 0, -1), 1.5)
>>> Phi = MultipoleExpansion({'discrete': False, 'rho': rho, 'xyz': XYZ}, l_max=2)

Evaluate the expansion at arbitrary points with Phi(x, y, z), or on the grid points of a continuous distribution with Phi[...].

__call__(*xyz, l_max=None)

Evaluate the multipole expansion at points with given coordinates.

Parameters:
  • *xyz (float | array_like, default: () ) –

    The x, y, z coordinates of the points where to evaluate the expansion. If three numbers are given, the expansion is evaluated at the single point (x, y, z). If arrays are given, it is evaluated at each point (x[i], y[i], z[i]). Arrays may have any shape; numbers and arrays are broadcast against each other.

  • l_max (int, default: None ) –

    Only use contributions up to this angular momentum. Defaults to the l_max the expansion was created with, and must not exceed it.
Returns:
  • float | ndarray –

    The value of the potential: a float for a single point, otherwise an array of the broadcast shape of the coordinates.

Examples:

>>> Phi(30.5, 30.6, 30.7)
>>> Phi(30.5, 30.6, 30.7, l_max=1)  # monopole and dipole only
>>> Phi(np.linspace(10, 20, 5), 0, 0)  # 5 points on the x-axis

__getitem__(key)

Evaluate the multipole expansion on grid points of the charge distribution.

Only available for continuous charge distributions.

Parameters:
  • key (index expression | array_like) –

    Slices, indices or a boolean mask selecting the points of the grid charge_dist['xyz'] at which to evaluate the expansion.
Returns:
  • ndarray –

    The values of the multipole expansion, in the shape defined by key.
Raises:
  • TypeError –

    If the charge distribution is discrete.

Examples:

>>> x, y, z = [np.linspace(-5, 5, 51)] * 3
>>> X, Y, Z = np.meshgrid(x, y, z, indexing='ij')
>>> rho = gaussian((X, Y, Z), (0, 0, 0), 1.5)
>>> mpe = MultipoleExpansion({'discrete': False, 'rho': rho, 'xyz': (X, Y, Z)}, l_max=3)

Evaluate on the whole grid (a 51x51x51 array) or on the plane z = -5 (a 51x51 array):

>>> mpe[:, :, :]
>>> mpe[:, :, 0]

Evaluate only on the boundary of the grid, using a boolean mask:

>>> mask = np.ones_like(rho, dtype=bool)
>>> mask[1:-1, 1:-1, 1:-1] = False
>>> boundary_values = np.zeros_like(rho)
>>> boundary_values[mask] = mpe[mask]
